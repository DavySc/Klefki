# Relative paths in user servers are flagged (2026-10-19)
Goal: PLAN "Nice to have" 6. A user-scope stdio server whose command names a path relative to where it starts (`node build/index.js`) works only in a folder that has that file. Klefki checks user servers from the home folder, so the check can say Connected while every session in a project fails.

- Real Claude Code 2.1.303 (temp `HOME` and `CLAUDE_CONFIG_DIR`, `claude mcp list`): user servers `node srv/s.js` and `node ./srv/s.js` are Connected from the home folder (which has `srv/s.js`) and fail from a project folder; `node s.js` connects only from `srv/`. A `cwd` key is ignored (still fails with an absolute `cwd`, and `add-json` drops it), so it is not a way out and is not suggested.
- Core `config/relative.rs` `relative_paths(entry)`: the program when it has a folder in it but is not a full path; arguments that are `.`, `..`, start with `./` `../` `.\` `..\`, or name a file of a known type (`server.py`, `build/index.js`, also as `--config=./x.json`); environment values the same, shown as `NAME=value`. Not relative: full paths (`/x`, `C:\x`, `\\nas\x`), `~` and `$VAR` (the `~` hint already exists), npm scopes `@x/y`, anything with a colon (addresses, `github:o/r`, drives, image tags), `mcp/fetch` and `owner/repo` without a file type. A folder option with a full path (`uv --directory /abs/weather run weather.py`, the MCP quickstart's own example; also `--cwd`, `-C`, ...) makes the rest found from there, so it is not flagged. Arguments the row hides as secrets and secret-sounding variables are never named. Cleaned, cut at 80 characters, at most 5, each once. Pure string work on the definition already read, no IO.
- `ServerRow::relative_paths`: filled for every stdio row (a move or copy to the user reuses it); only user rows are flagged.
- App: badge "relative path" (warn colour, after "casing") with hover text; the General tab says which parts, why a session fails and why the check can pass, above the definition editor.
- Review: a warning for each server the plan writes for the user (add, save, move or duplicate to the user) that still has relative paths; none for a local target, a fixed definition or a toggle. Claude Code's own commands only add OAuth servers, which are addresses, so only `.claude.json` edits are looked at.
