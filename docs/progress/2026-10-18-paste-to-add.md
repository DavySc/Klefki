# Paste to add (2026-10-18)
Goal: the first slice of the M2 add wizard, pulled forward from PLAN "nice to have" 3. Before this there was no Add button; a new server could only come from Duplicate.

Commits: `dacb73d` (the slice), then the review fixes below (the next commit on `claude/paste-to-add-jqir5m`).

Done:
- **core `paste.rs`**, public as `api::Pasted` / `api::PastedServer`. `Pasted::parse(text)` reads, and never runs:
  - `claude mcp add` (`-s/--scope`, `-t/--transport`, `-e/--env` and `-H/--header` with their variadic values, `--opt=value`, `--`) and `claude mcp add-json`, one command per line or joined with `;` or `&&`. Written in the key order Claude Code writes (`type, command, args, env` / `type, url, headers`). An address without `--transport` is read as http, with a note.
  - Shell words like a POSIX shell, plus PowerShell `` ` `` and cmd `^` line continuations; a backslash only escapes what a shell needs, so `C:\tools\x.js` keeps its backslashes. `$VAR` / `${VAR}` become `${VAR}` (Claude Code fills it in at start), with a note naming them. Pipes, redirects, `&`, `$(…)` and backticks are refused: the text is never a shell script.
  - JSON: `{"mcpServers": …}`, VS Code's `{"servers": …}`, a map of names, a `"name": {…},` fragment, or one unnamed definition. Definitions are kept as written.
  - Git Bash's `cmd C:/ …` is turned back into `cmd /c …` (PLAN nice-to-have 3), with a note.
  - Per server: sanitised name and one-line summary, `scope` (local is Claude Code's default; none for JSON or `-s project`, which gets a note), a `problem` (from `entry::validate`, OAuth options, unknown options, missing parts), and `${VAR}` hints for secret-looking env/header values (never the value). Limits: 256 KiB, 100 servers, 64 KiB per definition.
- **engine/ops:** `Change::Add { name, json, targets }` → `Op::AddServer` per target (the existing docstore path; no `ops.rs` change to existing ops beyond moving Duplicate's place checks into `new_places`, now shared). Name checked, definition validated, OAuth refused (it must go through `claude mcp add-json --client-secret`), unknown project refused, a name taken in a target refused, other scopes' servers of that name warned about. The review shows the full command and arguments and which of the user's variables are read; typed-in env/header values are hidden. A note says Klefki checks the new server right after, which starts it. Summary "Add fs for the user and in b", button "Add".
- **app:** toolbar **Add** (+), **Ctrl+N**, palette "Add a server" (last, so servers stay in view of an empty search). The dialog reads the text as it changes (only when it changes), lists each server with an editable name, its summary, why it is left out, and secret hints; notes below. Places reuse Duplicate's list (now `Places`, shared). Default place: the selected server's project when every command is local, else the user; a place ticked by hand is kept. Ctrl+Enter or Review prepares one plan.
- **Review fixes** (a code review of `dacb73d`; each with a test, seen failing by reverting the fix): a command whose program path is quoted (`"C:\Program Files\…\claude.exe" mcp add …`) was taken for JSON; a line needing a shell (a README's `curl … | sh`) refused the whole paste, now only that line is skipped (or that add command is refused with the reason); the review showed a typed-in value next to a reference (`sk-live-123${SUFFIX}`, `${T:-default}`), now only the variables are shown; JSON remote servers without `type` (Cursor's shape) get `"type": "http"` with a note; `~` in a command or argument gets a hint (Claude Code starts servers without a shell); a quoted `\` + CRLF continuation; "Adds 5 servers" instead of a long list (shared `list_in_words`). Review now re-reads and re-checks what it sends at the moment it is pressed (defensive: a same-frame edit could not be reproduced in egui_kittest, so no test). Not changed: the app's `name_problem` capitalisation (moved, not new) and core's sentence style differ slightly.
- **Fix found on the way:** the review dialog ran off a short window (720 px) with a few servers, hiding Add/Cancel. Its body now scrolls and the buttons stay in view; dialogs that change size draw once more so they are centred before the next click (`settle`).
