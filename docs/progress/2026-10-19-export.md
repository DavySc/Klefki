# Export (M3), 2026-10-19
Goal: PLAN.md's Export. Selected servers (or every server in the list) as one `{"mcpServers": {…}}` block that can be copied, with header, env and secret values written as `${VAR}` references. Klefki's Add (paste) reads the block back, which covers Import for now. `klefki-cli export` prints the same block.

## Done
- Core `export.rs`: makes the block and lists the variables to set. Every env and header value becomes a reference (a header keeps its `Bearer`/`Basic`/`Token` scheme). So does each argument, address part (user name and password, secret query parameters) or other setting that looks secret. Existing references stay, and their names are never reused. One value gets one variable, and a different value under a taken name gets `NAME_2`. Variable names come from names or bare flags only, never from anything that could hold a value. A server whose definition cannot be read is left out with a note. The same definition in two places is exported once; two different ones with one name become `NAME_2`. Bidi and control characters are written as `\u` escapes.
- `secretlike.rs`: `shown_args` is now `rewritten_args` with a replacement callback (`…` for showing, `${VAR}` for export), so both use one set of rules. Shown output is unchanged (its tests are untouched).
- `inventory::server_entries` reads `.claude.json` once and each `.mcp.json` once for any number of servers.
- Engine: `Command::Export(ids)` and `Event::Exported`. `api::export(ids)` is the same without an engine, for the CLI.
- App: an Export button (icon `EXPORT`) after Move. Its hover says whether it takes the selection or the list. A palette entry: with a selection it sits among the selection's actions; without one it comes after Add, so the "Go to" entries stay in view. The dialog shows the variables, notes and the read-only block, sized to fit the window. Copy (Enter) turns into "Copied", and Close or Esc closes it. With a selection, rows the search hides now are still exported. Only the answer to the last request fills the dialog.
- CLI: `klefki-cli export [NAME...]`. The block goes to stdout; variables and notes go to stderr. Exit 1 if a server was left out, 2 for an unknown name or `--json`. Decision 006 and the README are updated.

It listed AUTH_TOKEN, GITHUB_PERSONAL_ACCESS_TOKEN, DB and LOG_LEVEL, the OAuth note, and a block with no secret. Copy changed to "Copied". At 800x480 the buttons stay on screen. The first try at 1200x720 ran off the bottom; the block's height now adapts.
- Acceptance tests were written alongside the code, not all seen failing first. Seen failing: secret query parameters after an address's user name and password were left in (fixed in `rewritten_address`), and a flag carrying a value (`--token=tok-…`) named the next variable after the secret (fixed: bare flags with letters only).

## Open
- Every env value is replaced, including plain settings like `LOG_LEVEL=debug`. This is safe by design (PLAN.md), but the user must set them again.
- No file save: the block is copied (the app) or redirected (the CLI). A Save button needs a file dialog and a write through core.
- Import has no button of its own: Add's paste reads the block.
