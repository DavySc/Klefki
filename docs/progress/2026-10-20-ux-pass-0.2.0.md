# UX pass before 0.2.0 (2026-10-20)

Goal: the owner asked for a full UX pass of main (04a0841, the 0.2.0 candidate) before tagging v0.2.0, with every
finding marked release-blocker or can-wait, and small, clearly safe fixes in one pull request.

## Findings
- The real app under Xvfb at 1200x720 and 800x480, light and dark, both grey families, with Claude Code 2.1.304 and a
  throwaway home holding user, local, project, plugin, organisation, policy-blocked and claude.ai servers. Keyboard
  order and accessible names were read with a throwaway egui_kittest probe (not committed).
- One release-blocker, sixteen can-wait items, each with a suggested fix and sources. The findings and screenshots
  are kept outside the repository, with the owner.

## Done (this branch)
- Duplicate keeps what was typed when Review fails. The plan could not be made (the secret store was locked, say),
  the toast said "press Review again", but the dialog was gone and the new name, client ID and client secret with it.
  The form now stays, hidden, until the plan comes; on failure it comes back as it was with the reason inside, as Add
  already did. The typed client secret is kept in the form (wiped when dropped) until then. Room is kept for the
  reason so the dialog still fits at 1200x720 and 800x480.
- Selecting a server no longer pushes the list down. "1 selected" was meant to sit beside the toolbar's buttons only,
  but the room was measured with `available_width()`, which in a wrapping row is not what is left on the line; it went
  on a line of its own and moved every row 46 px under the pointer. Now `available_size_before_wrap()`.
- A profile's "Tick at least one server." goes as soon as a server is ticked, not on the next Save; a message that
  still holds stays, and none is said before Save.
- Using a profile in every project: "In 2 projects, this also turns off a, b and c, …"; after the names the count read
  as the last server's.

## Checks
- New or changed tests, each seen failing first: `duplicate_comes_back_as_it_was_when_its_plan_cannot_be_made` (also
  failed with no room kept for the reason), `a_failed_plan_for_something_else_leaves_a_closed_duplicate_closed`,
  `duplicate_suggests_a_name_and_the_same_place` (the form now goes when the plan comes),
  `selecting_a_server_does_not_move_the_list` (4 window sizes), `a_new_profile_is_made_from_the_servers_ticked_in_it`,
  `what_save_said_stays_while_it_still_holds`, core `using_a_profile_alone_names_every_server_it_turns_off`'s
  every-project wording.
- `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` (app 418,
  core 901, cli 25 and 33), `cargo deny check`: exit 0.
- Real app: Duplicate with a locked store comes back with the name and client ID typed and the reason, inside the
  window; clicking a row leaves the list where it was.
